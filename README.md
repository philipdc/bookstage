# Release notes 


BookStage Alpha 0.2.0

An AI first pre accounting workbench.

It is free and open source, it works with TurboCASH (Free and Premium) and will soon work with other accounting packages.

Note this is ALPHA release and should only be used by enthusiasts, depending on the interest and take up, it should evolve rapidly. The more collaborators I get, the faster it will develop. It may not be fully functional yet, but it should give an idea of what is possible for software that is AI first.

Download:


Install:
Run "BookStage Setup 0.2.0.exe".

Navigate to Help > Getting Started – if you need more than that it is badly written software and we will improve it. (context sensitive AI is on its way – just trying to figure out how to deliver it as near to free as possible.

Don’t install to “Program files” or write protected folders.

This alpha includes demo TurboCASH books and sample bank statements.
Start BookStage from the Windows Start Menu after installation.

This is still an alpha release. Use demo data first and back up any TurboCASH books before testing with real data.

Makes Verison 0.1.0 obsolete. Still focuses on  Bank Statements, but now includes Help and Example files

For TurboCASH and AI enthusiasts only. Expect many changes before release.
