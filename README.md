# Release notes 

This alpha includes demo TurboCASH books and sample bank statements.
Start BookStage from the Windows Start Menu after installation.

This is an alpha release. Use demo data first and back up any TurboCASH books before testing with real data.

For TurboCASH and AI enthusiasts only. Expect many changes before release.

This first release has focused on importing Bank Statments into TurboCASH. More generalised documents and mainstream accouting packages to follow.
