A BookStage workbench, is an SQLite database and a set of subdirectories. The SQLite database contains details of the sub directory structure below the workbench and a JSOn representation of the documents in the subdirectories and the workflows in processing them.
An good analogy for a workbench is the lever arch files that cluttered old acocutngin offices. The documents arepreaccounting elents that are used to load data into the azccoutnign package.
Every work bench has a name, the path to where it is found. The list of the subdirectrories. Optionally a pathe to the TurboCASH set of book associateds with the workbench

The folder holding the workbench can also contain books.fdb the Firebird SQL file for the TurboCAHS set of Books.
Typically tthe subdirecrtories contain:
 Documents (invoices, credit notes, purchases, Good return Notes, quoptes, purtchase orders, delivery notes)
Bank Statements
Tax Returns
Debtors reconciliations
Credit Recoinciliations

A workbench can be  an added local, network, or an internet location. 
    • Black text: project books folder.
    • Bold black text: another directory on this PC.
    • Dark blue text: mapped network drive.
    • Red text: internet workbench.
Bookstage keeps track of recently opened workbenches.
Add a workbench will create a new diredctory with SUBDIRECTIORES.
To delete a workbench use Delete. Thi will delete the power bench and all directories below that workbench. Take care this is dangerous.

When you Open  a workbench it will read information for the associated set of TurboCASh books and display that information in youR main pane.
